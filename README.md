# oreslang-data-science

Native Oreslang libraries for numerical computing, columnar data, statistics, data pipelines, and data-oriented programming.

This repository intentionally keeps the core userland implementation in Oreslang rather than Java. The long-term target is a fast, ergonomic data-science stack with NumPy/pandas/Polars-class workflows while preserving Oreslang's scheduler, ownership, AOT, and heterogeneous CPU/GPU design.

Development happens through pull requests from `main`.
